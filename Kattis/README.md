# Kattis Solutions

144 problems solved from [open.kattis.com](https://open.kattis.com), organized by problem type.

Kattis problems are generally lighter on data structures than LeetCode — most test clean I/O handling, arithmetic, and logical reasoning. The difficulty here is mostly about reading the problem statement carefully and handling edge cases.

---

## Topics

| Topic | Problems | What it covers |
|-------|----------|----------------|
| [Conditionals and Logic](./Conditionals%20and%20Logic/) | 67 | If/else branching, boolean reasoning, case handling |
| [Math and Arithmetic](./Math%20and%20Arithmetic/) | 27 | Formulas, numeric computation, unit conversions |
| [Simulation](./Simulation/) | 11 | Step-by-step process simulation |
| [Strings](./Strings/) | 38 | Character inspection, string manipulation, encoding |
| [Sorting](./Sorting/) | 1 | Ordering and comparison |
